## 三、已知问题与风险

| 类别 | 问题 | 建议 |
| --- | --- | --- |
| 字体路径 | `assets/ref/css/*.css` 内 `static/fonts/...` 解析到不存在的 `assets/ref/css/static/fonts/`（真实字体在 `assets/static/fonts/`），部署后 Font Awesome/Element 图标可能 404 | 复制字体目录 / 改 CSS 路径 / 加部署重定向 |

## 四、建议实现优先级

**P0（核心业务闭环）**：用户认证 → 分镜方案生成 API → 视频生成任务流水线 → 积分计费扣费
**P1（内容生产闭环）**：链接解析/上传 → ASR 转录 → 总结/思维导图 → 内容创作生成
**P2（商业化闭环）**：真实支付下单与回调 → 订单/积分记录 → 会员权益校验
**P3（运营与体验）**：管理后台五模块 → 博客/文档内容管理 → 通知系统 → 前端交互缺口修复与多语言
