# 项目总览

## 1. 项目定位

VidSpark 是一站式 AI 音视频理解与多平台内容创作平台。当前仓库 `vidspark-static` 是其**纯静态前端演示工程**（HTML + CSS + 原生 JS，无构建工具、无框架、无后端）。

多数页面的 DOM 是从线上 Vue 2 + Element UI 应用**服务端渲染后扒取的快照**（保留了大量 `data-v-xxx` 作用域属性、`router-link-active`、`<!---->` 占位注释、`href="#/"` 哈希路由残留），交互由页面底部追加的内联 `<script>` 手工补回。所有业务数据（用户、任务、热门视频、模型列表、费用、文章内容）全部写死在 HTML 中，**全站没有任何 fetch / XHR / AJAX 请求，也没有使用 localStorage**。

## 2. 技术栈

| 项 | 说明 |
| --- | --- |
| 页面 | 17 个静态 HTML 文件，根目录平铺 |
| 样式 | 两套并存体系（见 §4）+ Font Awesome 6.5.2 图标 |
| 脚本 | 原生内联 JS + `assets/js/main.js` + `assets/js/submit-toast.js` |
| 部署 | GitHub Actions → Netlify（`netlify deploy --prod`），触发分支 `master` |
| 演示素材 | `guide-assets/`（2 个 .mov 示例成片 + 7 张截图）、`readme-assets/`（全站页面截图） |

## 4. 样式体系（两套并存、互不相通）

1. **`assets/ref/`（Vue 产物提取）**：`chunk-libs.css` / `app.css`（Tailwind 风格工具类）/ 5 个页面级 chunk / `chunk-6df7e2b6.css`（品牌色）+ `override.css`（手写补丁）。被 login、register、membership、member-center、payment、docs 系列、blog 系列、workbench、404 等页面全量链接。
2. **`assets/css/style.css`（手写设计系统）**：紫色主色（`--primary:#7c3aed`）设计令牌 + 按钮 / 导航 / 卡片 / 表单 / 定价卡等组件，仅被 `admin.html` 与 `storyboard-studio.html` 使用。

`override.css` 的关键作用：① 年付模式 `.plan-grid.yearly-mode` 三列布局；② 强制 `.opacity-0/.translate-y-20/.reveal` 可见（静态版无滚动揭示 JS）；③ 404 页全套布局与云朵动画。

**已知隐患**：ref CSS 中字体路径写为相对路径 `static/fonts/...`，CSS 位于 `assets/ref/css/` 会解析为不存在的 `assets/ref/css/static/fonts/`（真实字体在 `assets/static/fonts/`），部署后 Font Awesome / Element 图标可能 404。

## 5. 导航与页面关系

```
index.html（首页）
 ├─→ storyboard-studio.html（分镜成片工作室）──→ workbench.html（出片工作台，返回回工作室）
 ├─→ dashboard.html（控制台：总结 / 创作 / 热门 / 详情）
 │     ├─ 侧栏"分镜" / 首页卡片 → storyboard-studio.html
 │     └─ 用户菜单 → membership.html / member-center.html
 ├─→ blog.html ──→ blog-article.html?id=<id>（4 篇）
 ├─→ docs.html ──→ docs-storyboard-workflow-guide.html
 │                └→ docs-video-model-prompt-guide.html
 ├─→ membership.html ──→ payment.html?plan=<plus|pro|ultra>&cycle=<monthly|yearly>
 └─→ login.html ⇄ register.html
admin.html（独立入口，"返回前台" → index.html）
404.html（Netlify 未知路径兜底）
```

几乎每页底部都有一段相同的**品牌点击补丁**：遍历元素找文本恰为 "VidSpark" 且带特定样式类的节点，绑定点击跳转 `index.html`。

## 6. 公共脚本能力（重要：已写好但大多未挂载）

### `assets/js/main.js`（仅被 admin.html 引用，且 admin 页无任何元素命中其钩子）
- 移动端导航开合、Tab 切换（`[data-tab-group]`）、分段按钮、定价月付/年付切换
- 全局 toast `window.vsToast(msg, ok)`、`[data-toast]` / `[data-open]` / `[data-close]` / `[data-collapse]` 事件委托、ESC 关闭模态
- 按钮文案正则反馈表（生成/保存/删除等 → toast）
- 表单提交守卫：非 `data-real` 表单 `preventDefault`，按按钮文案提示"登录成功/注册成功/提交成功"

### `assets/js/submit-toast.js`（被 index.html 引入但从未调用）
- 右下角"提交成功 / 系统正在分析您的视频内容..."通知卡，暴露 `window.vsSubmitToast.show(desc)`

## 8. 部署流程

`.github/workflows/deploy.yml`：push 到 `master` 或手动触发 → `checkout` → Node 20 → `npm i -g netlify-cli` → `netlify deploy --prod --dir=.`（凭证存于 secrets）。根目录存在 `404.html`，Netlify 自动兜底未知路径。

待改进：整仓部署会发布 `Readme.md`、`readme-assets/`、`guide-assets/`（含视频），建议加 `.netlifyignore`；无 CLI 缓存；无 `netlify.toml`。

## 9. 跨页面共性问题

1. **绝对路径跳转**：多处使用 `/dashboard.html`、`/storyboard-studio.html`、`/guide-assets/...`，需根路径部署，本地 `file://` 直接打开会失效。
2. **链接残留与错链**：首页"查看完整文档"指向线上 `vidspark.cn` 而非本地文档页；`blog.html` "返回首页"是 `href="#/"` 残留；登录页"忘记密码"是死链。
3. **装饰性交互**：全站语言切换（中文/English）无逻辑、首页汉堡按钮无移动菜单、"退出登录/联系我们/微信"按钮无行为。
4. **数据不一致**：博客列表日期 2026-03-01 与文章内页"3月2日"不一致；首页版权 ©2025、博客页脚 ©2026；admin 订单套餐（¥49/¥299/¥399/连续包月/团队版）与定价页体系（¥15.9/¥39.9/¥89.9）冲突。
5. **文案笔误**：首页"可是化思维导图"（应为"可视化"）；微信公众号图标 `title="未知来源"`；联系邮箱 `xxxxxx@gmail.com` 占位。
