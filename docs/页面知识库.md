- **CTA**："进入控制台" → `dashboard.html`

## 3. storyboard-studio.html — 分镜成片工作室（998 行，单文件自包含）

两阶段工作流核心页。左右双栏（300px 侧栏 + 主区），顶部步骤条：**阶段1 分镜方案 → 阶段2 分镜成片**。

### 侧边栏
品牌区（→index）；收起侧栏【实】；新任务【实：回表单视图、重置步骤条】；项目列表（种子项目"未来城市" id=2382【假】，新建会 innerHTML 覆盖，刷新丢失）；用户头像【假】。

### 视图一：新建任务表单（5 大配置面板，17+ 字段，选择用 `data-s1` 单选 / `data-m1` 多选事件委托）
1. **创意简报**（必填）：3000 字文本域 + 计数【实：≥2 字符启用生成】
2. **基础配置**：AI 创作模型自定义下拉（7 模型 + credit）、方案数量（1/2套）、总时长滑杆（4–60s）、画面比例（6种）【实】
3. **视觉风格**：整体风格（12种）、画质（4档）、镜头效果（4项多选）、光影氛围（11项）【实：仅选中态切换】
4. **运镜与节奏**：运镜偏好（15项）、转场（10项）、叙事节奏（7项）【实】
5. **声音与台词**：台词开关→联动语言/旁白风格子区块；配乐倾向（11项）【实】
6. **高级设置**：情绪基调（13项）、色彩基调（10项）、附加指令【实】

### 生成流程（伪实现）
校验 → 截取简报前 8 字为项目名 → 注入侧栏（⚠️ innerHTML 拼接，**XSS 风险**）→ 随机项目 ID → 4 条加载文案轮播（每 1100ms，约 4.4s）→ 渲染方案。
- 种子项目输出 `SEED_PLANS`：两套精心撰写的 15 秒未来城市分镜提示词范文（方案A"上帝俯览" / 方案B"沉浸穿梭"，各 4 个分镜含画面描述/镜头信息/旁白）【假】
- 新建项目输出 `buildPrompt()`：按总时长均分两段的固定 cinematic 模板——**用户简报正文与绝大多数配置项并未真正参与生成**【假】

### 视图二：项目工作区
左侧 360px 摘要栏（创意/模型/风格/比例/时长/画质，部分由 `fillSummary` 回填）；右侧方案页签 A/B 切换【实】+ 提示词预览 `<pre>` + 一键复制【实但降级不完整】+「进入出片工作台」→ `workbench.html`；阶段二出片概览"0 / 2 片段已完成"【假】，三处按钮均硬链到 `workbench.html`。

### hash 机制
`syncHash()` 写入 `#/storyboard-studio/<id>?stage=plan|video&plan=0|1`（与线上路由格式对齐）；`initFromHash()` 加载时解析，匹配数字 ID 一律回落种子项目 2382。
